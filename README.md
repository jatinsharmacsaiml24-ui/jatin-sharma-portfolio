# Jatin Sharma — AI/ML Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript. No build step or paid dependency is required.

## Run locally

1. Extract this folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing

- LinkedIn and GitHub profile links are already configured.
- Add public GitHub repository/demo links to the four project cards if available.
- Review all resume-derived figures and wording before publishing.
- Contact email and profile links were supplied by Jatin Sharma. Review them once before publishing.

## Free hosting

You can deploy this static folder using GitHub Pages, Netlify or Vercel free tiers. Upload the folder/repository and select the root directory; no build command is needed.
